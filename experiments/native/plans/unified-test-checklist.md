# 原生层统一测试清单

## 测试前统一项

- 确认统一使用 `GET /api/attack-library` 中的攻击 case
- 确认四位成员记录字段一致
- 确认截图命名方式一致
- 确认 Agent 名称与版本记录方式一致

## 每次测试记录

- Agent 类型
- Agent 名称
- Agent 版本
- 攻击家族
- case 编号
- 是否适用
- 攻击是否成功
- 是否被拦截
- 拦截阶段
- 任务是否完成
- 是否误拦截
- 额外时延
- 审计日志路径
- 截图路径
- 备注

## 建议截图内容

- 攻击输入
- Agent 输出或执行结果
- 安全机制拦截提示
- 如有审计日志，也截取关键片段
