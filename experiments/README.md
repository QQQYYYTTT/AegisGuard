# Experiments

This directory stores experiment assets for later report writing and replay.

- `native/`: pure agent baseline and native security tests
- `guardrail/`: third-party or traditional defense comparison
- `aegisguard/`: experiments with the project system enabled

Recommended contents for each layer:

- `plans/`: test plan and environment notes
- `cases/`: attack prompts and benign tasks
- `results/`: tables, logs, exported summaries
- `notes/`: ad hoc observations and conclusions
- `screenshots/`: evidence for the report and demo
