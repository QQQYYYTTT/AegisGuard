### 2. 主题色覆盖

在它的 `style/element-plus.scss` 或 `style/variables.scss` 里：

```scss
// 安全色板
:root {
  --aegis-primary: #1a5f9e;      // 国密蓝
  --aegis-success: #67c23a;        // Allow/安全
  --aegis-warning: #e6a23c;        // Quarantine/人工审批
  --aegis-danger: #f56c6c;        // Deny/阻断
  --aegis-info: #909399;          // Degrade/降级
  
  // 风险等级色
  --risk-low: #67c23a;
  --risk-medium: #e6a23c;
  --risk-high: #f56c6c;
  --risk-critical: #ff4d4f;
}
```

### 3. 保留 vs 删除清单

| 它的原内容 | 处理方式 | 原因 |
|-----------|---------|------|
| `views/welcome.vue` | 替换为 `views/dashboard/index.vue` | 改造成系统总览 |
| `views/error/` | 保留 | 404/403页面通用 |
| `views/login.vue` | 简化 | 竞赛项目登录可以简化 |
| `layout/components/TagView` | 可选保留 | 多标签页，如果不需要可以关闭 |
| `store/modules/permission.ts` | 简化 | 你们不需要复杂RBAC，简化成登录态即可 |
| `store/modules/settings.ts` | 保留 | 主题、布局设置 |
| `hooks/usePermission.ts` | 简化或删除 | 不需要复杂权限判断 |
