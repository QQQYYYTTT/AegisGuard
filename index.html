Agent Runtime Security Governance

AegisGuard

面向 Agent 运行时的安全监管与执行控制系统，围绕可信授权、执行前阻断、双流上下文隔离与攻击链审计构建完整防护闭环。

核心能力
  • 策略中心按任务、会话和动作动态签发 RequireToken 授权令牌
  • Message Gate、Action Gate、Return Gate 输出可执行控制动作
  • 记忆沙箱将外部结果隔离到低信任流，仅允许结构化安全摘要回传
  • 审计日志与攻击图谱记录从检测到处置的全链路证据

System Overview

从可信授权到执行前阻断的 Agent 运行时安全闭环

平台以控制平面和执行平面协同工作，围绕授权、检测、阻断、隔离、审计五类能力，构建可验证、可执行、可解释的运行时安全治理体系。

当前能力焦点 BLOCK

在危险动作真正落地前完成校验、决策与控制，而不是只在事后记录风险。
